# Design System — Standard Commercial Kitchen Equipment's

## Aesthetic
Premium industrial B2B — white/light-grey base, steel silver accents, single orange CTA highlight. Corporate trustworthy modern. NO dark themes.

## Palette
| Token | Value | Usage |
|---|---|---|
| Background | #ffffff | Page base |
| Section alt | #f5f5f5 | Alternating sections |
| Light muted | #efefef | Subtle dividers |
| Text primary | #111827 | Headings |
| Text secondary | #374151 | Body |
| Text muted | #6b7280 | Captions, labels |
| Steel accent | #9ca3af | Icons, borders |
| Orange brand | #f97316 | CTAs ONLY |
| Orange dark | #ea6d0c | CTA hover |
| Border | #e5e7eb | Cards, dividers |

## Zone Backgrounds
| Zone | Class |
|---|---|
| Navbar | bg-white/90–95 (sticky, glass) |
| Hero | bg-white or bg-[#f5f5f5] |
| Section alternation | bg-white / bg-[#f5f5f5] |
| Footer | bg-[#f5f5f5] with white bottom bar |

## Typography
- Display/headings: Inter bold
- Body: Inter regular/medium
- Tracking: widest for uppercase labels

## Components
- Navbar: white sticky, dark text, orange active underline, orange CTA button
- Footer: 4-column light grey, white bottom bar
- WhatsApp FAB: fixed bottom-right, green (#25D366)
- Cards: white bg, border-[#e5e7eb], subtle shadow on hover
